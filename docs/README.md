# docs

- `commandes/` : toutes les commandes du projet, classees par besoin. Source en Markdown,
  version `.txt` generee par `make docs-txt`.
- `adr/` : les decisions d'architecture, une par fichier, jamais reecrites.
- `journal/` : le journal de bord, source du chapitre "Difficultes rencontrees et solutions".
- `architecture/` : les schemas.
- `RUNBOOK.md` : quoi faire quand quelque chose casse.
- `DEMO.md` : le deroule minute de la soutenance et le plan B.
